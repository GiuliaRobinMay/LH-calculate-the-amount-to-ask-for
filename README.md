# Lesko Help — Calculate My Funding Amount

A member tool for the **Lesko Toolbox** (Mighty Networks space "Calculate My Funding Amount",
space id 24870522). It answers one question: *how much should I ask for?*

Same pattern as the other Lesko App Lab tools ("What Should I Ask For?", Credit Score Coach):
one static HTML file, vanilla JS, everything stays on the member's device, no sign-up,
never asks for an SSN or bank details, embedded in the community via iframe.
